If the lights run away

Unplug the Stream Deck’s USB cable and don’t press anything else. If one press changes lots of cues, or Lightkey freezes, this stops it at once.

Run the rest of the service from Lightkey’s own panel with the mouse, and tell whoever looks after the lighting afterwards.

Before every service

  1. Plug the charger in. The lid can stay closed: the Mac runs from the external screen, keyboard and mouse, but only while it’s on the charger. If the Mac is shut down, unplug the charger and plug it back in to start it.

  2. Look at Booth Check in the menu bar. A tick means ready; a triangle or cross with a number means something needs fixing, so click it. When the Mac starts, Booth Check opens the show and Stream Deck itself, and opens its window if anything is wrong.

  3. If Lightkey or the Stream Deck app isn’t open, click the Booth Check icon → Get the show started. It opens the show, waits for Lightkey to be ready, then opens the Stream Deck app, in that order.

  4. Hold Option and click Lightkey’s green window button to make it fill the screen. Don’t use true full screen: it moves Lightkey into its own space, and macOS can then let the Stream Deck app fall asleep.

  5. In the Stream Deck app, check “Lightkey v33 Service Panel” is the profile in use. Booth Check can’t see which profile is selected.

  6. Press House 10% on the deck, then press it again. The house lights should come up and the key light, then both go off. If that works, the whole chain works.

Something’s wrong Find the symptom. “Now” is for whoever is in the booth; “For good” is the one-time setup below.

One-time setup Done once by whoever looks after the Mac.

  1. Install Booth Check. Download Booth.Check.zip from github.com/jimhoggey/BoothCheck-App/releases and drag Booth Check into Applications. First time only, unblock it with xattr -dr com.apple.quarantine "/Applications/Booth Check.app" in Terminal, or Privacy & Security → Open Anyway. After that it updates itself.

  2. Tell it what this Mac does, choose the show, allow access. Pick Booth Mac. Choose show… → the show file. Allow control of System Events. On “The right show is open”, click Allow access…, turn Booth Check on under Accessibility, then reopen it.

  3. Work down Booth Check’s list until everything is a tick. Each item says what to do. Anything that changes the Mac shows the exact command first and runs only when you press Run; anything needing the admin password opens System Settings instead, except starting from the charger, which shows its one sudo command first.

  4. The settings Booth Check can’t see. Privacy & Security → Allow accessories to connect → Always. Lock Screen → screen saver and “Require password…” → Never. Control Centre → Focus → Do Not Disturb, on.

  5. Turn off the Stream Deck app’s own “launch at login”. Booth Check opens it once Lightkey is ready; starting on its own, it can beat Lightkey and the keys stay dead.

  6. Look after the battery. An always-plugged-in Intel MacBook can swell its battery: turn on battery health management (System Settings → Battery → ⓘ next to Battery Health). If the case bulges or the trackpad lifts, get the battery replaced.

Without Booth Check

Switch App Nap off (then restart), and stop the Mac sleeping on the charger:

defaults write -g NSAppSleepDisabled -bool true
sudo pmset -c sleep 0 displaysleep 0 disksleep 0

Leave it on

Leave it on, plugged in and logged in, all week. With the lid closed, shut down from the Apple menu and start it by replugging the charger; a vertical stand keeps it cooler. Restart about once a month, a few days before a service, and install macOS updates then.

Why restarts ask for a password

With FileVault on, unlocking the disk is the login, so each restart needs the password once before Booth Check can start the show. Turning FileVault off allows automatic login, but anyone who takes the laptop could read it. Restarting rarely gets the same result.
