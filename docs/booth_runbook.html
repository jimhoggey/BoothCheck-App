Lighting Booth Runbook

How to get the booth Mac ready before a service, what to do when something goes wrong, and the one-time setup that stops most of it happening at all.

If the lights run away

Unplug the Stream Deck’s USB cable and don’t press anything else. If one press changes lots of cues, or Lightkey freezes, this stops it at once.

Run the rest of the service from Lightkey’s own panel with the mouse, and tell whoever looks after the lighting afterwards.

Before every service

  1. Plug the charger in and open the lid. The Mac only stays awake on power, and a closed lid puts it to sleep.

  2. Open Lightkey and check the window title says BackupChurch_modular_v33. If it shows an older name, choose File → Open Recent and pick v33. The folder holds many old versions.

  3. Hold Option and click Lightkey’s green window button to make it fill the screen. Don’t use true full screen: it moves Lightkey into its own space and macOS then lets the Stream Deck app fall asleep.

  4. Open the Stream Deck app, choose “Lightkey v33 Service Panel”, and leave its window open behind Lightkey. An app with no window showing is the first thing macOS decides isn’t busy.

  5. Press House 10% on the deck, then press it again. The house lights should come up and the key light, then both go off. If that works, the whole chain works.

Something’s wrong Find the symptom. “Now” is for whoever is in the booth; “For good” is the one-time setup below.

Deck keys do nothing — then they all fire at once when you click the Stream Deck app.

macOS has put the Stream Deck app to sleep. Your presses are queued inside it, not lost.

Now

Stop pressing — every queued press fires when it wakes. Click the Stream Deck app once.

For good

Setup 1 and 2, and never use true full screen.

A key is lit but its cue isn’t on, or the other way round.

The deck can only update keys on the page it’s showing. Worship and flow, the two mover pages and the two bar pages share groups across pages.

Now

Press any key on the page you’re looking at. Lightkey’s own panel is always right.

The deck does nothing at all, even with the app open.

The wrong profile is selected, or the keys aren’t sending to Lightkey.

Now

In the Stream Deck app, pick “Lightkey v33 Service Panel”. Still dead: open any key’s settings and check Midi Out says Lightkey Input.

Cues change in Lightkey but nothing lights up.

The USB DMX interface isn’t reaching the lights.

Now

Reseat the DMX USB cable at both ends, then quit and reopen Lightkey.

Setup 3.

One-time setup Done once by whoever looks after the Mac. Needs the admin password.

  1. Stop macOS putting apps to sleep (App Nap).

    This is what freezes the Stream Deck. It is switched off for every app, because the Stream Deck’s MIDI plugin runs as a separate program. Open Terminal and run:

    defaults write -g NSAppSleepDisabled -bool true

    Restart the Mac, then check it took — this should print 1:

    defaults read -g NSAppSleepDisabled

  2. Make sure Low Power Mode is off.

    It throttles background apps hard. This should print 0; if it prints 1, set System Settings → Battery → Low Power Mode to Never.

    pmset -g | grep lowpowermode

  3. Never sleep while on the charger.

    sudo pmset -c sleep 0 displaysleep 0 disksleep 0

    The -c means on the charger only. If someone unplugs it, it still sleeps on battery instead of running flat.

  4. Stop the USB prompt. System Settings → Privacy & Security → Allow accessories to connect → Always.

  5. No password after sitting idle. System Settings → Lock Screen: “Start Screen Saver when inactive” → Never, and “Require password after screen saver begins or display is turned off” → Never.

  6. No surprise updates. System Settings → General → Software Update → the ⓘ next to Automatic Updates: turn off “Install macOS updates” and “Install Security Responses and system files”. An update can reset the USB permission and the MIDI setup, so install them yourself in the monthly restart (below).

  7. Everything opens by itself. System Settings → General → Login Items → Open at Login: add Elgato Stream Deck and the show file BackupChurch_modular_v33.lightkeyproj itself, which starts Lightkey with that exact show. Swap the file when the version changes. If it won’t take the file, drag the file to the Dock so it’s one click away.

  8. Keep notifications off the screen. Control Centre → Focus → Do Not Disturb, left on permanently on this Mac or scheduled over service times.

Leave it on

Leave the Mac on, plugged in, lid open and logged in, all week — no need to shut it down after a service. Restart it about once a month, a few days before a service, never the morning of, and install updates then. If something breaks, you have days to fix it.

Why restarts still ask for a password

With FileVault on, unlocking the disk is the login, so every restart needs the password once. Turning FileVault off allows automatic login, but then anyone who takes the laptop can read everything on it. Keeping it on and restarting rarely gets the same result.
