Starting a service

About two minutes. Most of it happens by itself.

  1. Check the Mac is on the charger. Screen black? Press a key. Mac off? Unplug the charger and plug it back in, then type the Mac’s password.

  2. Wait for “Ready for the service”. A panel at the top right ticks through the start-up. If Lightkey asks for the password to connect to the lights, type it.

  3. No panel, or not all green? Click the Booth Check icon at the top right of the menu bar, then Get the show started.

  4. Check the Stream Deck shows the house-light keys, 2% to 100%. Another page? Press the arrow key until they’re back.

  5. Test: press House 10%, then press it again. The lights come up, then go off. You’re ready.

Ending a service

Leave everything running for next time.

  1. Haze off. Stream Deck, Punch FX & Haze page: press Haze Off.

  2. Stage lights off. Stream Deck, Worship Colour page: press Stage Off.

  3. House lights to what the room needs next. For example, House 100% for packing down.

  4. Leave the Mac on. Don’t quit Lightkey, don’t shut the Mac down, and keep the charger plugged in. Booth Check keeps it ready.

Asked to shut it down? Apple menu → Shut Down. To start it again, unplug the charger and plug it back in.

If the lights run away

Unplug the Stream Deck’s USB cable and don’t press anything else. If one press changes lots of cues, or Lightkey freezes, this stops it at once.

Run the rest of the service from Lightkey’s own panel with the mouse, and tell whoever looks after the lighting afterwards.

Something’s wrong Find the symptom. “Now” is for whoever is in the booth; “For good” is the one-time setup below.

The Booth Check icon shows a triangle or a cross.

Something it checks needs attention. The number is how many things.

Now

Click the icon. Each item says what to do; Open Booth Check shows the full list, with a button for each fix.

Deck keys do nothing — then they all fire at once when you click the Stream Deck app.

macOS has put the Stream Deck app to sleep. Your presses are queued inside it, not lost.

Now

Stop pressing — every queued press fires when it wakes. Click the Stream Deck app once.

For good

Booth Check switches App Nap off at start-up; quit and reopen Stream Deck once.

A key is lit but its cue isn’t on, or the other way round.

The deck can only update keys on the page it’s showing. Worship and flow, the two mover pages and the two bar pages share groups across pages.

Now

Press any key on the page you’re looking at. Lightkey’s own panel is always right.

The deck does nothing at all, even with the app open.

Wrong profile, or Stream Deck started before Lightkey was ready.

Now

Pick “Lightkey v33 Service Panel”. Still dead: quit and reopen the Stream Deck app.

For good

Setup 3 and 5, so Booth Check opens them in order.

Cues change in Lightkey but nothing lights up.

The USB DMX interface isn’t reaching the lights. Booth Check’s two DMX items help tell.

One-time setup Done once by whoever looks after the Mac.

  1. Install Booth Check. Download Booth.Check.zip from github.com/jimhoggey/BoothCheck-App/releases and drag Booth Check into Applications. First time only, unblock it with xattr -dr com.apple.quarantine "/Applications/Booth Check.app" in Terminal, or Privacy & Security → Open Anyway. After that it updates itself.

  2. Tell it what this Mac does, choose the show, allow access. In This Mac, switch on Lightkey (with the DMX option), Stream Deck, Stays on for services, and Start the show when the Mac starts. On the main window, Choose show…. Allow control of System Events. On “The right show is open”, click Allow access…, turn Booth Check on under Accessibility, then reopen it.

  3. Work down Booth Check’s list until everything is a tick. Each item says what to do. A change shows its exact command first and runs only when you press Run; most admin changes open System Settings instead.

  4. The settings Booth Check can’t see. On Apple silicon Macs, Privacy & Security → Allow accessories to connect → Always (Intel Macs don’t have it). Lock Screen → screen saver and “Require password…” → Never. Control Centre → Focus → Do Not Disturb, on.

  5. Turn off the Stream Deck app’s own “launch at login”. Booth Check opens it once Lightkey is ready; starting on its own, it can beat Lightkey and the keys stay dead.

  6. Look after the battery. Always on the charger, an Intel MacBook’s battery can swell: turn on battery health management (Battery → ⓘ next to Battery Health), and replace it if the case bulges.

  7. Restart about once a month, a few days before a service, and install macOS updates then. Each restart asks for the password once: with FileVault on, unlocking the disk is the login.

Without Booth Check

Switch App Nap off (then restart), and stop the Mac sleeping on the charger:

defaults write -g NSAppSleepDisabled -bool true
sudo pmset -c sleep 0 displaysleep 0 disksleep 0
